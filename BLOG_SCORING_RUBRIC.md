# Blog Scoring Rubric — 0-100 SEO Score + Traffic Estimation

Every blog post gets scored on a 0-100 scale. This helps you see which content is working and which needs optimization.

---

## 📊 **SEO Score Formula**

```
Final Score (0-100) = 
  (Keyword Research Score × 0.20) +
  (Content Quality Score × 0.25) +
  (E-A-T Signals Score × 0.20) +
  (Technical SEO Score × 0.20) +
  (Competitive Ranking Score × 0.15)
```

Each section scored 0-100, then weighted.

## 🎯 **Traffic Estimation Formula**

**Based on keyword research + ranking position, estimate traffic:**

### **Conservative (Realistic)**

```
Estimated Traffic = 
  (Search Volume × CTR at Position X) × 0.8

Example:
  Keyword Volume: 420/mo
  Estimated Position: 5 (day 30)
  CTR at position 5: 4.5% (avg)
  
  Estimate = (420 × 0.045) × 0.8
           = 18.9 × 0.8
           = 15.1 visitors/mo
```

### **Optimistic (If You Rank Top 3)**

```
Estimated Traffic = 
  (Search Volume × CTR at Position 1-3) × 1.2

Example:
  Keyword Volume: 420/mo
  Estimated Position: 3 (good case)
  CTR at position 3: 14% (avg)
  
  Estimate = (420 × 0.14) × 1.2
           = 58.8 × 1.2
           = 70 visitors/mo
```

### **Average CTR by Position**

| Position | CTR % | Notes |
|----------|-------|-------|
| 1 | 28% | Featured snippet can push to 35-40% |
| 2 | 15% | Second choice |
| 3 | 10% | Below the fold on many devices |
| 4 | 7% | Start of page 2 |
| 5 | 5% | |
| 6-10 | 2-3% | Rare to reach |
| 11-20 | <1% | Most users don't scroll this far |

## 💰 **Lead Estimation**

**How many leads will this blog generate?**

```
Blog Visitors/mo × Conversion Rate = Leads/mo

Conservative conversion:
  150 visitors × 2% = 3 leads/mo

Optimistic conversion:
  150 visitors × 5% = 7.5 leads/mo

Note: 
  - B2B SaaS average: 2-5% CTR on CTA
  - Top performers: 5-15%
  - 24Observe is free tier, so conversion may be higher (10%+)
```

## ✅ **Decision Tree**

**After scoring, what do you do?**

```
If SEO Score 80-100:
  ✅ KEEP as-is. Link from social media, newsletters.

If SEO Score 60-79:
  ⚠️ OPTIMIZE. Improve internal links, add more research, update H2s.

If SEO Score 40-59:
  🔧 REWRITE. Major issues (weak keyword, poor E-A-T, bad links).

If SEO Score < 40:
  ❌ UNPUBLISH. Too many problems. Save as draft, fix, republish.
```
